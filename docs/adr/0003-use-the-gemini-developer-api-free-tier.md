# Use the Gemini Developer API Free Tier

Description Generation uses the Gemini Developer API free tier to avoid usage charges during the private prototype. This accepts the provider's stated free-tier data-use terms, under which submitted Item Photos and Descriptions may be used to improve its products; a paid tier can be adopted later but cannot undo the handling of earlier submissions. Members will not be shown a confirmation or information about this data handling in the app.
